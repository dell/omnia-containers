mount_params

dict

Named mount parameter profiles. Each profile provides defaults for fs_type, mnt_opts, dump_freq, fsck_pass. Custom fields are allowed for backend-specific metadata.

<mount_params_key>

dict

Dynamic key matching pattern: ^[a-zA-Z0-9_-]+$
