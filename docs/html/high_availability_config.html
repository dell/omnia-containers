Parameter

Details

service_k8s_cluster_ha

list / elements=dict / required

High Availability (HA) configuration for Kubernetes (K8s) service clusters. Service K8s clusters are supported only in HA mode.

cluster_name

string / required

Required. Name of the Kubernetes service cluster. Must match the service cluster name defined elsewhere.

Minimum length: 1.

enable_k8s_ha

boolean / required

Mandatory. Must be true. Service Kubernetes cluster deployment is supported only in HA mode.

virtual_ip_address

string / required

Mandatory. Virtual IP address used as the Kubernetes API endpoint for the service cluster setup.
