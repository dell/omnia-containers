Parameter

Details

service_k8s_cluster

list / elements=dict / required

List of service Kubernetes cluster configurations.

cluster_name

string / required

Non-empty, case-sensitive name of the cluster on which you want to deploy Kubernetes. Cluster names must be unique within this list.

deployment

boolean / required

Indicates if Kubernetes will be deployed or not.

Accepted values: true or false

Set this value to true on exactly one service Kubernetes cluster entry. Input validation rejects configurations with no selected cluster or with multiple selected clusters.

enable_powerscale_csi

boolean

Enables PowerScale CSI on the cluster selected with deployment: true. When enabled, both PowerScale driver file paths are required. The default is false.

etcd_on_local_disk

boolean / required

Determines whether ETCD is deployed on local disk or NFS storage.

Accepted values: true or false

When set to true, ETCD is deployed on local disk on all master nodes. The system prioritizes BOSS card if available, and falls back to SSD/SATA disks if BOSS is not present. The /var/lib/etcd directory is mounted on the selected local disk.

When set to false, ETCD storage is provisioned using NFS, and no local disk configuration is performed for ETCD. The field cannot be omitted.

Important

  • Migration from NFS to local disk is not supported during upgrades. This configuration is only applicable for fresh installations.

k8s_cni

string / required

Kubernetes SDN network.

Schema-accepted values: calico or flannel

Supported provisioning value: calico. The current path always stages and applies Calico; flannel passes input validation but does not select a Flannel manifest.

pod_external_ip_range

string / required

Ordered IPv4 range or IPv4 CIDR used by the load balancer for assigning external IPs to Kubernetes services.

The range must not overlap the service CIDR, pod CIDR, or any DHCP pool. It must not contain an OIM admin or BMC address, or any ADMIN_IP, BMC_IP, or IB_IP from the PXE mapping file.

Ensure that the pod_external_ip_range defined in the omnia_config.yml file is reachable from the OpenManage Enterprise appliance and the SFM network.

Sample values: 172.16.107.170-172.16.107.200

k8s_service_addresses

string / required

Canonical IPv4 network used internally for Kubernetes services.

It must not overlap the pod CIDR, external pool, or any physical network in network_spec.yml.

Sample value: "10.233.0.0/18"

k8s_pod_network_cidr

string / required

Canonical IPv4 network used to assign addresses to individual pods.

It must not overlap the service CIDR, external pool, or any physical network in network_spec.yml.

Sample value: "10.233.64.0/18"

nfs_storage_name

string / conditional required

When Kubernetes functional groups are selected, the entry selected with deployment: true must define a non-empty value that exists in storage_config.yml. Its matching mount must also set mount_on_oim: true. Entries with deployment: false are not deployed and need not define this value.

csi_powerscale_driver_secret_file_path

string / conditional required

Required when enable_powerscale_csi is true. Specify an absolute path to an existing regular secret.yaml file that satisfies the PowerScale CSI input contract.

csi_powerscale_driver_values_file_path

string / conditional required

Required when enable_powerscale_csi is true. Specify an absolute path to an existing regular, plaintext values.yaml file that satisfies the PowerScale CSI input contract.

k8s_crio_storage_size

string / required

Specifies the disk size allocated for CRI-O container storage.

k8s_bootstrap_token_ttl

string

Duration for which kubeadm bootstrap tokens remain valid. Bootstrap tokens are used by worker and control-plane nodes to authenticate when joining the cluster.

After this duration, tokens are automatically deleted and operators must regenerate them by running the refresh script on the first control-plane node: <nfs_k8s_mount_point>/generate-control-plane-join.sh (e.g., /opt/omnia/k8s_mount/generate-control-plane-join.sh).

Acceptable formats: Go duration strings accepted by kubeadm (e.g., "1h", "2h", "4h", "24h").

Setting to "0" disables expiry (not recommended for security reasons).

Default value: "2h"
