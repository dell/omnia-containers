Parameter

Details

gitlab_cert_dir

string

Directory on target host where cert artifacts are generated/stored. Accepted values: absolute path string. Default: /root/gitlab-certs

Minimum length: 1.

gitlab_default_branch

string / required

Default branch for repository and API operations. Accepted values: valid git branch name. Default: main

Minimum length: 1.

gitlab_host

string / required

Target host IP for GitLab deployment. Accepted values: valid IPv4 address. Cannot be empty.

Minimum length: 1.

gitlab_https_port

integer / required

HTTPS port exposed via GitLab NGINX. Accepted values: valid port number (1-65535). Default: 443

Range: 1-65535.

gitlab_min_cpu_cores

integer

Minimum CPU core count required before install. Accepted values: integer >= 1. Default: 2

Minimum: 1.

gitlab_min_memory_gb

integer

Minimum RAM in GB required before install. Accepted values: integer >= 1. Default: 4

Minimum: 1.

gitlab_min_storage_gb

integer

Minimum free disk space in GB required before install. Accepted values: integer >= 20. Default: 20

Minimum: 20.

gitlab_project_name

string / required

Name of the GitLab project Omnia will create/manage. Accepted values: alphanumeric string starting with a letter or digit. Default: omnia-catalog

Minimum length: 1.

gitlab_project_visibility

string / required

GitLab project visibility. Accepted values: private, internal, public. Default: private

gitlab_puma_workers

integer

Puma web worker count. Scale with CPU count. Accepted values: integer (1-64). Default: 2

Range: 1-64.

gitlab_repo_script_url

string

URL for the GitLab package repository setup script. Override only when pinning to gitlab-ee or a specific version.

Minimum length: 1.

gitlab_sidekiq_concurrency

integer

Sidekiq background job concurrency. Accepted values: integer (1-200). Default: 10

Range: 1-200.

gitlab_ssh_port

integer

SSH port for git+ssh operations. Accepted values: valid port number (1-65535). Default: 22

Range: 1-65535.

gitlab_ssl_dir

string

Final SSL directory consumed by GitLab Omnibus. Accepted values: absolute path string. Default: /etc/gitlab/ssl

Minimum length: 1.

oim_api_verify_ssl

boolean

Verify SSL certificate when connecting to OIM API. Set to false for self-signed certs. Accepted values: true or false. Default: true
