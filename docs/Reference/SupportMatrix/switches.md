| PowerSwitch S5232F-ON | Certified |
| PowerSwitch S4148 | Certified |
| PowerSwitch Z9432-ON | Certified |
| PowerSwitch Z9264F-ON | Certified |
| PowerSwitch N3248TE-ON | Certified |
| PowerSwitch Z9664F | Certified |
| PowerSwitch Z9864F-ON | Supported |

!!! note

    - The switches that have reached EOL might not function properly. Use switch models mentioned in the support matrix.
    - Omnia requires OS10 to be installed on ethernet switches.
    - Ethernet switches running SONiC OS will have to be configured manually by users.
