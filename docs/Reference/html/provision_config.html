Parameter

Details

additional_cloud_init_config_file

string

Path to additional cloud-init configuration file for stateless node provisioning. Leave empty to disable.

Default: .

default_lease_time

string / required

Default lease time for DHCP.

Pattern: ^[0-9]+$

Default: 86400.

dns_enabled

boolean

Enable DNS-based hostname resolution via coresmd.

Default: False.

kernel_version_override

string

Optional kernel version to pin for boot image selection. Leave empty to auto-select latest.

Pattern: ^(|[0-9]+\.[0-9]+\.[0-9]+-.+$)

Default: .

language

string / required

Language setting.

Default: en_US.UTF-8.

pxe_mapping_file_path

string / required

Path to the PXE mapping file.
