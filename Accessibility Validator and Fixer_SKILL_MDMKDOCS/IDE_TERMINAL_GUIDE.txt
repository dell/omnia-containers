STEP 1: INITIAL VALIDATION
--------------------------------------------------------------------------------
Command:

What it does:
- Scans all RST files in the docs directory recursively
- Checks for accessibility issues (alt text, links, code blocks, etc.)
- Generates a JSON report with all findings
- Creates backups of files before validation
- Automatically creates output directories if they don't exist

- Summary of issues found

COMMAND REFERENCE
--------------------------------------------------------------------------------

VALIDATOR COMMANDS:

Options:
  -r: Recursive scan of subdirectories
  -o json: Output in JSON format
  -f: Output file path
  --no-backup: Disable automatic backup of RST files before validation

STRUCTURED REPORTING COMMANDS:
python structured_reporting.py <input_json> <output_directory>

Arguments:
  input_json: Path to accessibility report JSON file
  output_directory: Where to save structured reports

FIXER COMMANDS:
python omnia_rst_accessibility_fixer.py <report_json> --auto-fix --auto-only

Options:
  --auto-fix: Enable automatic fixes
  --auto-only: Only apply automatic fixes, skip interactive
  --comparison-report: Path to comparison report
  --no-backup: Skip creating backups

python generate_comparison.py <before_json> <after_json> <output_file>

Arguments:
  before_json: Baseline report JSON file

  output_file: Where to save comparison report

TROUBLESHOOTING
--------------------------------------------------------------------------------

Python not found:
- Ensure Python 3.7+ is installed
- Add Python to system PATH
- Use 'python3' instead of 'python' if needed

Permission errors:
- Run terminal as administrator (Windows)
- Check file permissions on docs folder
- Ensure write access to reports folder

Module not found errors:
- Install required dependencies:
  pip install docutils

Memory errors with large documentation:
- Process documentation in smaller batches
- Use --no-backup option to skip backups
- Close other applications to free memory

Backup creation errors:
- Fixed in latest version - backup now uses absolute paths
- If backup still fails, use --no-backup to disable
- Backups are created in docs directory as .omnia_backup_TIMESTAMP
