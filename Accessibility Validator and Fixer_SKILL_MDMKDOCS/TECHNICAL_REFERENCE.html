📋 Detailed Workflow Steps

Step 1: Initial Validation

Scans Markdown files for accessibility issues and generates baseline report.

python omnia_md_accessibility_validator.py path/to/docs -r -o json -f reports/baseline_validation/accessibility_report.json

Step 2: Generate Structured Reports

Creates detailed text reports from the JSON validation output.

python structured_reporting_md.py reports/baseline_validation/accessibility_report.json reports/baseline_validation

Step 3: Run Automatic Fixer

Automatically fixes issues that can be resolved without human intervention.

python omnia_md_accessibility_fixer.py reports/baseline_validation/accessibility_report.json --auto-fix --auto-only

Step 4: Post-Fix Validation

Re-validates documentation after fixes to measure improvement.

python omnia_md_accessibility_validator.py path/to/docs -r -o json -f reports/current_status/accessibility_report_after.json

Step 5: Generate Current Status Reports

Creates reports for the post-fix state.

python structured_reporting_md.py reports/current_status/accessibility_report_after.json reports/current_status

Step 6: Generate Comparison Report

Compares baseline and post-fix states to show improvement.

python generate_comparison_md.py reports/baseline_validation/accessibility_report.json reports/current_status/accessibility_report_after.json reports/comparison_report.txt

Step 7: Generate HTML Visual Report with Pie Charts

Creates interactive HTML report with pie charts showing severity distribution before and after fixes.

python generate_visual_report_md.py reports/baseline_validation/accessibility_report.json reports/current_status/accessibility_report_after.json reports/visual_report.html

Step 8: Generate Excel/CSV Report

Exports data to CSV for analysis in spreadsheet applications.

python generate_excel_report_md.py reports/baseline_validation/accessibility_report.json reports/current_status/accessibility_report_after.json reports/excel_report.csv

Step 9: Generate Unfixed Issues Report

Lists issues that remain unfixed for manual review.

python generate_unfixed_report_md.py reports/current_status/accessibility_report_after.json reports/unfixed_issues_report.txt

🚀 Command-Line Arguments

run_omnia_accessibility.py

python run_omnia_accessibility.py [docs_path] [options]

Options:

  • --fix-mode {auto,interactive,both,validate-only} - Fix mode to use
  • --step {all,validate,fix,report} - Specific step to run
  • --no-backup - Skip backup creation (not recommended)
  • --output-dir - Custom output directory for reports

omnia_md_accessibility_validator.py

python omnia_md_accessibility_validator.py [path] [options]

Options:

  • -r, --recursive - Scan directories recursively
  • -o {json,text} - Output format
  • -f [file] - Output file path
  • --config [file] - Custom config file

omnia_md_accessibility_fixer.py

python omnia_md_accessibility_fixer.py [report_file] [options]

Options:

  • --auto-fix - Apply automatic fixes
  • --auto-only - Only fix auto-fixable issues
  • --interactive - Interactive fixing mode
  • --no-backup - Skip backup creation

🆘 Troubleshooting

Common Issues

Issue: "No module named 'json'"
Solution: Ensure Python 3.6+ is installed. The json module is built-in.

Issue: "Permission denied when writing to files"
Solution: Run with appropriate permissions or check file permissions.

Issue: "Report file not found"
Solution: Ensure the validation step completed successfully before running the fixer.

Issue: "Backup directory cannot be created"
Solution: Check write permissions in the target directory or specify a different backup location in config.

🔄 Report Formats Explained

JSON Report

Machine-readable format containing all issue details, file paths, line numbers, and metadata. Used as input for fixer and report generators.

Text Report (Structured)

Human-readable format with organized sections by severity and issue type. Includes recommendations for each issue.

HTML Visual Report

Interactive HTML with CSS-based pie charts showing severity distribution before and after fixes. Includes tables and visual comparisons.

CSV Report

Spreadsheet-compatible format for data analysis, tracking metrics over time, and generating custom reports.

Comparison Report

Side-by-side comparison of baseline and post-fix states, showing fixed issues, remaining issues, and improvement percentage.
