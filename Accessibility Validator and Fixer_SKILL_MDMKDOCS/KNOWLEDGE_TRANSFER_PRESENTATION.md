# The Problem & Solution

## ❌ Current Challenges

- 📝 Markdown documentation needs accessibility compliance
- 🔍 Manual checking is time-consuming and error-prone
- ⏱️ Teams spend hours finding and fixing accessibility issues
- 📊 No easy way to track improvement over time

## ✅ Our Approach

### Three Core Capabilities

1. **Validate** - Automatically scans Markdown files for accessibility issues
2. **Fix** - Auto-fixes issues + interactive mode for manual review
3. **Report** - Multi-format reports with pie charts showing before/after

---

# How It Works & Key Features

## ⚙️ Simple Workflow

**SCAN → VALIDATE → FIX → REPORT**

### One Command

```bash
python run_omnia_accessibility.py path/to/docs
```

### Recent Enhancements (v1.5)

- **10-Step Workflow**: Complete automation from validation to HTML clickable links
- **Checkpoint Mode**: Three-phase execution for review before fixes and before publishing
- **HTML Clickable Links**: Direct file:// URLs to view fixed issues in rendered documentation
- **False Positive Fixes**: Disabled empty paragraph check (blank lines required in Markdown)

## 🌟 What Makes It Unique

- 📄 Markdown-specific (not generic HTML/DITA tools)
- 🤖 Auto-fixes 40%+ of issues automatically
- 📊 Visual reports with pie charts (before/after comparison)
- 🔄 Tracks improvement over time with comparison reports
- 📦 Zero external dependencies (Python standard library only)
- 🎯 IDE-ready for Windsurf/Devin integration
